## ⚙️ Engineering Principles & Best Practices

### 🛡️ Infrastructure & Deployment

- **Immutable Infrastructure:** despliegues reproducibles mediante Terraform e imágenes Docker.
- **Container Security:** uso de imágenes base ligeras y buenas prácticas de seguridad.
- **State & Secrets Management:** gestión de configuraciones y credenciales mediante variables de entorno y recursos de Kubernetes.

### 💻 Code & Architecture

- **Clean Architecture:** estructuración modular orientada a la mantenibilidad.
- **Version Control:** flujos de trabajo con Git, Conventional Commits y ramas de funcionalidades.
- **Observability Mindset:** logging estructurado y preparación de métricas para monitoreo.

### 💰 Finora — Personal Finance Manager

<a href="https://github.com/overrun1026/Proyecto-Finora-Finanzas">
<img src="https://opengraph.githubassets.com/1/overrun1026/Proyecto-Finora-Finanzas" width="100%" alt="Vista previa del proyecto Finora" />
</a>

Finora es una aplicación web para la gestión de finanzas personales que permite organizar transacciones, administrar presupuestos, realizar seguimiento de objetivos de ahorro y consultar informes financieros. Su arquitectura integra una API backend desarrollada con FastAPI, persistencia en PostgreSQL y una interfaz web construida con HTML, CSS y JavaScript.

El proyecto utiliza SQLAlchemy para el acceso a datos, Alembic para las migraciones de la base de datos y Docker Compose para ejecutar los servicios. Nginx se encarga de servir el frontend y gestionar las solicitudes hacia el backend.
